
# DocumentationPractice

## Deskripsi
DocumentationPractice adalah proyek Java sederhana untuk latihan membuat dokumentasi dan menggunakan Git.

## Fitur
- Menjalankan program Java sederhana.
- Menampilkan pesan pada console.
- Mendokumentasikan proyek menggunakan README.

## Persyaratan
- Java Development Kit (JDK).
- IntelliJ IDEA.

## Cara Menjalankan
1. Buka proyek DocumentationPractice di IntelliJ IDEA.
2. Buka file Main.java.
3. Jalankan method main().
4. Lihat hasil program pada console.

## Contoh Output
Hello, GitHub!

## Teknologi
- Java
- IntelliJ IDEA
- Git dan GitHub
