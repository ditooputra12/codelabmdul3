
# DocumentationPractice

## Deskripsi
DocumentationPractice adalah proyek Java sederhana untuk latihan dokumentasi dan version control.

## Persyaratan
- Java Development Kit (JDK)
- IntelliJ IDEA

## Cara Menjalankan
1. Buka proyek di IntelliJ IDEA.
2. Buka file Main.java.
3. Jalankan method main().
4. Lihat hasil program di console.

## Contoh Output
Documentation Practice

## Teknologi
- Java
- IntelliJ IDEA
- Git
- GitHub
